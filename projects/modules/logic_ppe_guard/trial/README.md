# 六类安全穿戴试用项目

适用于本项目的 RK3588 系统镜像。包内带有可执行程序、推理库、现场六类模型、标签、配置和一段约 45 秒的现场视频。

## 开始验证

在 Web 控制台的程序管理中上传 `ppe_guard_six.tar.gz`，保留独立程序名 `ppe_guard_six`，选择 `config.json` 启动。进入实时预览，或用播放器打开 `rtsp://板卡IP:8564/ppe`。在已安装的程序目录执行 `./vision_analysis ./assets/config.json` 也会以相同配置启动托管服务。同一块板的推理应用共享 NPU 独占锁。

默认回放一次。可以在文件播放控制里拖回开头，也可以把通道的视频源改成自己的视频。换文件时保留模型和逻辑参数。用命令行运行时，本地告警在 `event_store/<事件ID>/`，Web 启动时则通过控制台告警箱查看。每条事件包含原图、标注图和业务字段。

## 画面怎么读

| 输入标签 | 判定和标记 |
| --- | --- |
| `person` | 用 ByteTrack 关联人员，人体框仅用于计算。 |
| `head`、`helmet` | 按现场标签约定，把通过位置和尺寸校验的露头作为未戴帽证据，帽子用于排除冲突。确认后在当帧露头处画红框。需要用戴帽样本检查模型的 head 类语义。 |
| `hand_bare`、`hand_gloved` | 用裸手框定位，和同一位置的手套框冲突时跳过。当前只运行检测模型，标签写“未戴手套”。看见一只裸手只框那只手，两只都有有效框时可以各画一框。 |
| `workwear_on` | 有明确归属的工装框可撤销该人的工装违规。试用配置开启缺正类推断，只有达到人框尺寸、分数及人员重叠检查才累计。橙框标出估算的躯干区域，标签带“推断”。柜体遮挡、蹲姿或检测器漏检仍可能导致误报。 |

默认在 4 秒窗口中收集至少 3 次违规证据，相邻采样间隔至少 250 毫秒，首尾跨度至少 1 秒。裸手阈值 0.5，露头阈值 0.75，穿戴正类阈值 0.35。证据窗口用于确认，同一帧里多个框不能加速确认。

当前帧找不到可靠位置时局部框消失；近期已确认状态可以保留到证据过期。一个跟踪会话首次确认时写入本地告警，同一会话后续出现其他部位仍能在画面显示。同一 ID 消失超过 3 秒后按新会话处理。换 ID、重新启动或重新回放可能产生新事件。首份抓拍保存触发时刻。

事件 JSON 的 `data.fields.regions` 含当前人员各部位的 `part/source/x/y/w/h`。坐标原点为左上角，以 `frame_width`、`frame_height`（当前 640 × 640）为基准。映射到原视频时分别乘以原视频宽、高与坐标系宽、高的比值。`detected` 是模型框，`inferred` 是估计区域。

## 本版验证记录

在 RK3588 上用随包的 45 秒片段完整回放，ByteTrack 和六类 YOLOv5 正常启动，推理约 25 帧/秒，这段视频未产生告警。另用独立测试配置把可见帽子临时作为触发器，验证事件写盘和抓拍。第 38 帧的测试事件记录头部框 (268, 41, 28, 33)，与标注图片一致。试用包使用正式的六类映射。该测试用于验证位置传递和上报，现场召回率与误报率仍需人工标注的违规视频评估。

## 现场验收

| 建议片段 | 核对结果 |
| --- | --- |
| 一只手裸露，另一只戴手套或被设备遮住 | 仅裸手处有红框。 |
| 同一人同时露头、裸手 | 两处可同时框出，坐标分别贴合露头和裸手。 |
| 已戴帽人员与露头人员并排、伸手交叉 | 关注框旁人员 ID。归属不明的手框应跳过。 |
| 穿工装的人走到柜后，再离开遮挡 | 检查是否有橙色误报，以及工装重新检出后框是否撤销。 |
| 已报警的人移动、短暂遮挡后出现 | 无位置时不残留旧框；记录重现后的 ID 和通知次数。 |

为便于下一版定位问题，请保留原视频时间点、人员 ID、原图及标注图，并注明期望框的位置。工装误报偏高时可先关闭 `workwear_require_positive` 单独验证头部和手部；六类权重在关闭该推断后没有未穿工装的直接证据。

## 继续开发

业务源码在框架的 `projects/modules/logic_ppe_guard/`，试用包的 `source/` 附本版模块和回归用例。引擎在 `engine/include/types.h` 定义单条结果的 `show_detection_box` 属性，在 `engine/src/media/display/result_renderer.cpp` 的检测绘图分支读取该属性。重新编译须使用含这两处改动的框架源码。

在框架根目录执行下面的命令。

```bash
cmake -S engine -B build/engine -DBUILD_PPE_TESTS=ON
cmake --build build/engine --target vision_analysis ppe_tests ppe_display_tests -j4
(cd build/engine && ctest -R '^ppe_' --output-on-failure)
```
