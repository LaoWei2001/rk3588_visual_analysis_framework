# 暂停计时示例

在画布中选择通道逻辑“测试：暂停计时示例”，输入使用视频文件即可，不需要模型。
现成配置位于 `projects/assets/pause_timer_demo.json`，视频路径填在通道的 `stream.url`。
画面右上方显示两行秒数，精确到一位小数：

- **分析**：使用 `ctx->timestamp_ms`，不计入暂停时间。
- **现实**：使用 `ctx->real_time_ms`，包含暂停时间。

正常播放时两者一起增加。暂停时业务函数不再执行，因此画面和两行数字都会定格；
例如在 3 秒时暂停 5 秒，继续后的第一帧大约显示“分析 3.0 秒，现实 8.0 秒”。
现实计时在继续时更新到实际经过的时长，不会在暂停画面上持续刷新。

`get_state` 为每路保存两种起始时间，当前时间减去起始时间就是经过的时长。
拖动进度时框架重置业务状态，两行计时都重新从 0.0 秒开始；暂停中拖动仍保持暂停。
同一份业务代码也可以用于摄像头，不需要根据视频源切换计时方法。
