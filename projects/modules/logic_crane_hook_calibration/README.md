# 吊钩动态圆心标定采集

本 Logic 用于播放吊钩视频时，采集不同吊钩高度对应的正常铅垂圆心。正式检测时，
`logic_crane_hook` 根据 `box_scale` 在这些圆心之间插值；安全圆半径始终使用统一的
`safe_radius`，不会随高度变化。本 Logic 只采集数据，不执行歪拉斜吊告警。

## 使用方法

1. 在 Web 画布中为一个视频通道连接吊钩检测模型。
2. 将通道 Logic 选择为“吊钩动态圆心标定采集”。
3. 播放视频，将吊钩停在正常铅垂的不同高度。
4. 等检测框稳定后，点击“保存正常铅垂圆心”。
5. 每个代表性高度保存 3～5 个样本，运行时会按 `box_scale` 分组平均并插值圆心。
6. 采集完成后将通道 Logic 切回“行车吊钩安全圆检测”，保持“启用动态圆心”开启，
   并让“动态圆心标定文件”指向下方 CSV。

默认数据追加保存到：

```text
assets/hook_height_calibration_samples.csv
```

CSV 字段包括保存时间、帧号、通道、跟踪 ID、置信度、检测框坐标和尺寸、中心点以及：

```text
box_scale = sqrt(box_width * box_height)
```

重复启动不会覆盖旧数据。如需开始一批全新的标定，请先备份或重命名已有 CSV 文件。
正式检测画面会显示“圆心:动态”和加载到的标定点数量；文件不存在或没有有效样本时，
会自动回退到手动配置的安全圆心。
