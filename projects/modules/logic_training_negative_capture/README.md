# 训练集负样本采集

本 Logic 用于从带检测模型的视频通道中自动采集“没有指定目标”的原始分辨率图片，适合补充
误检场景、纯背景和困难负样本。图片写盘在独立后台线程执行，不直接阻塞业务帧处理。

## 画布连接

```text
视频流 → YOLO推理节点 → 训练集负样本采集
```

必须保持该通道推理开启；推理关闭时无法区分“没有目标”和“没有运行模型”，因此会暂停采集。

## 参数

- `target_class_id`：需要观察的目标类别编号；`-1` 表示任意类别。
- `min_score`：达到该置信度才认为目标存在。
- `capture_abnormal_count`：勾选“采集目标数量异常帧”后，仅当符合条件的目标数不等于 1
  （0 个或多于 1 个）时采图；适合画面中永远有且只有一个吊钩、需要收集漏检和多框误检的场景。
  未勾选时保持原行为，只在目标数为 0 时采图。
- `max_images`：本次 Logic 运行期间成功保存的图片上限。
- `capture_interval_sec`：刚进入目标丢失状态时立即采一张，持续丢失时按该间隔采集。
- `output_dir`：图片输出目录，默认 `@app_data/training_negative_samples`。
- `jpeg_quality`：JPEG 保存质量。

普通模式下目标重新出现后停止采集；数量异常模式下目标数恢复为恰好 1 个后停止采集。之后再次
进入采集条件时会立即开始下一段采集。达到图片上限后自动停止，修改
参数或重启 Logic 可以开始新一轮。图片通过 `ctx->source_frame()` 获取，尺寸与解码后的视频源
分辨率一致，不受模型输入尺寸和浏览器窗口大小影响。

运行后还可以进入“实时画面 → 自定义功能”，点击“手动保存当前原始帧”。手动截图不受目标
是否存在和推理开关影响，同样保存视频源分辨率图片并计入 `max_images`；文件名前缀为 `manual`。

默认通过 Web 安装为 `test_hangche` 时，图片目录为：

```text
/opt/ai_apps/.data/test_hangche/training_negative_samples/
```

该目录独立于程序包，更新或选择“只删除程序”时会保留；选择“全删”时才会一起删除。直接从
源码启动、没有 Web 注入的应用数据目录时，`@app_data` 回退为当前目录下的 `runtime_data`。

文件名包含通道号、采集 Unix 毫秒和帧号，格式类似：

```text
negative_ch01_1790648000123_f4281.jpg
```
