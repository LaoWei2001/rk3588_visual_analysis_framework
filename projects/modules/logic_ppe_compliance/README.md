# 作业人员安全穿戴检测

本模块将模型结果按人员跟踪框关联，对明确检出的未戴安全帽、未穿工作服、裸手/未戴手套目标累计多帧证据。任一违规类别在时间窗口内满足观测次数和最小时间跨度后，发布 `ppe_alarm` 并创建一次 `logic_ppe_violation` 事件。

## 模型编排

在通道中配置人员检测/跟踪模型，以及能明确输出违规状态的检测模型。人员结果必须有有效 `track_id`。通过模块参数填写模型实际标签，例如：

- 人员：`person`
- 未戴安全帽：`no_helmet` 或 `bare_head`
- 未穿工作服：`no_workwear` 或 `no_uniform`
- 未戴手套：`bare_hand` 或 `no_glove`

多个别名用英文逗号分隔。标签应按实际模型类别表调整。若模型只输出 `person`、`helmet`、`uniform`、`glove` 等正向类别，单纯缺少装备检测结果不会被本逻辑判成违规；应增加明确的违规分类，或先由专门的部位/可见性算法产出可靠违规检测结果。

## 关联和确认规则

- 违规检测框中心必须落在唯一一个人员框内；同时落在多个人员框内时按归属不明处理，不累计证据。
- 没有有效人员 `track_id` 的检测不参与按人报警。
- 违规类别必须显式出现并达到置信度阈值；没有检测到装备、人体部位被遮挡或看不清均不会推断为违规。
- 每种违规独立累计证据。默认 4 秒窗口内至少 3 次观测，证据跨度至少 1 秒，相邻证据至少间隔 250 毫秒。
- 首次满足条件时创建事件；同一 `track_id` 后续出现其他违规类型只更新画面状态，不重复创建通知。

## 当前边界

这是一层结果编排逻辑，不能替代人员跟踪、部位可见性、姿态/分割或装备分类模型。它使用跟踪器给出的 `track_id` 作为去重身份；若遮挡导致同一人换了 ID，或多人交换位置后跟踪器串 ID，本模块无法仅凭现有结果可靠恢复 `person_session_id`，因此不能保证跨 ID 的同一真人只报警一次。需求文档中的事件持久化、跨轨迹接续、左右手独立状态、多摄像头身份合并和追加更新同一事件，需要跟踪/身份服务及事件更新接口配合。

当前图片适合做机位与遮挡分析，单张图不能验证跨帧跟踪和报警去重。默认阈值是现场调试起点，需用连续视频评估误报、漏报、身份归属和报警延迟。
