# RK3588 现场网络配置工具

这是一个可独立运行的终端图形化网络配置工具，适合设备第一次到现场时使用。它提供
类似 `top` 的全屏界面、按钮式菜单和选择弹窗，并把系统网络状态翻译成现场人员容易
理解的中文。工具直接读写 RK3588 系统中的 NetworkManager 连接，不依赖 Web 平台、
后台服务或网络接口名称约定。

如果同时安装了本项目的 Web 平台，两边看到和修改的是同一批系统连接：

- Web 保存的有线或无线连接，会出现在 C 工具的“已保存的连接”中。
- C 工具永久保存的连接，会出现在 Web 的“已保存的连接”中。
- 任意一边启用、删除或修改后，另一边刷新或重新进入即可继续管理。
- 设备名称直接写入系统，两边读取的也是同一个名称。

Web 主要用于查看网络和后续维护；摄像头搜索、笔记本直连、临时配置、系统初始
设置和清除全部连接等首次部署或高风险功能只放在 C 工具中。

## 构建与运行

```bash
cd first_net_config
./build.sh
sudo ./first_net_config
```

默认会进入全屏终端界面：方向键选择，`Enter` 确认；在子菜单、输入框或确认框按
`Esc` 会取消当前操作或返回上一级，不会跨过中间页面。只有明确标注“返回主菜单”的
按钮才会直接回到主菜单；主菜单中的“退出程序”才会结束程序。主菜单和子菜单选项、
确认/取消/清空以及停止监测按钮都支持鼠标点击，列表也支持滚轮浏览。终端窗口
过小或不支持全屏显示时会自动退回纯文字界面，也可手工强制使用原来的
纯文字模式：

```bash
sudo ./first_net_config --plain
```

构建需要 CMake、C 编译器和 ncursesw 开发库。运行需要 root 权限、NetworkManager
和 `nmcli`；修改设备名称时还需要 `hostnamectl`。工具不需要 Web 服务处于运行状态。

## 主要功能

- 以简短卡片列出已保存连接，状态分为“已连接”“网线未接”“已启用”和“未连接”，
  并显示地址设置和是否自动连接。已启用连接也可修改；IPv4 或无线身份变更会先经过
  临时副本验证和自动回退保护。删除已启用连接需要输入
  完整高风险确认词。
- 设置有线网络，支持自动获取地址和固定 IP、子网掩码、网关、最多 4 个 DNS，
  并可设置自动、主用、备用或自定义路由优先级。
- 搜索附近的无线网络，支持无密码、WPA/WPA2、WPA3 和隐藏网络，并可设置自动或
  固定地址。目标 Wi-Fi 不在现场时，也可以只保存名称、密码和地址参数而不连接测试，
  设备以后进入覆盖范围时由 NetworkManager 自动连接；无线连接同样支持路由优先级。
- 查看全部网卡、当前 IP、默认联网方式和远程连接所用网卡，并检查网段冲突；有线
  网口会分别显示“已连接”“网线未接”“已启用”或“未连接”，避免把仅启用配置但
  未插网线的网口说成“正在使用”。
- 菜单 15“网络检查与修复”检查 IPv4 默认路由抢占和活动网卡网段冲突。
  默认路由可临时移除或永久修复；网段冲突可选择并删除确认不再需要的连接。
- 菜单 16“实时质量曲线”列出已启用的有线和 Wi-Fi 网络，并自动选择合适的指标。
  两类连接都会显示到网关的滚动丢包率和平均延迟；Wi-Fi 还显示信号百分比、dBm、
  最近约 30 秒的信号曲线和接入点切换，有线网络则显示物理链路、速率、双工和
  错误/丢弃包增量；带网关的连接还会绘制延迟和丢包曲线。
  全屏界面按 `Esc`/`Q` 可返回网络选择页，纯文字模式按
  `Ctrl+C` 可安全返回主菜单。
- 搜索摄像头并为所选有线网口设置同网段地址，不修改摄像头本身。
- 设置笔记本直连维护网络。
- 查看或修改设备名称，测试指定 IPv4 地址能否连接。
- 每次新建连接都可明确选择临时或永久保存。临时连接不会写入磁盘，设备或网络
  服务重启后消失。
- 网络切换带独立的超时保护。当前 SSH 因换 IP 断开时，可以通过新 IP 重新登录并
  再次运行工具确认；超时未确认会自动恢复修改前的连接。
- 提供制作镜像时保存系统初始网络设置、预览恢复内容、恢复初始设置，以及清除全部
  已保存连接的独立高风险功能。

## 已保存的连接

主菜单选择“管理已保存的连接”后，工具只列出日常需要管理的有线和无线连接，不再
直接显示一大段原始命令输出，也不会把内部连接标识展示给现场人员。每项连接可以：

1. 使用：先选择匹配的有线或无线网卡，再经过连接检查和超时确认。
2. 修改连接信息：可以重新设置自动/固定 IPv4、子网掩码、网关、DNS、路由优先级、
   连接显示名称和自动连接；无线连接还可以修改 SSID、隐藏属性和密码方式。
   已启用连接使用临时副本验证，并带跨 SSH 自动回退；未连接项下次启用时生效。
3. 补充/修改 DNS：可单独保存最多 4 个 IPv4 DNS，不修改 IP、网关或路由；
   已启用连接优先通过 `nmcli device reapply` 无断线生效。
4. 修改路由优先级：可设置自动、主用（优先级 100）、备用（优先级 600）或自定义；
   数值越小越优先。已启用连接会尝试无断线重新应用，但仍可能改变默认联网方式。
5. 删除：未连接项用 `y/N` 确认；已启用项需输入
   `DELETE ACTIVE`。删除已启用连接会立即移除对应的系统连接配置，可能使对应网卡
   断网，而且不会自动回滚。如果该网卡承载当前 SSH，工具会额外警告，
   并尽量保证断线后删除命令仍执行完。

这里的连接就是系统连接，不是 C 工具自己的副本，因此不会和 Web 平台形成两套互不
相干的数据。

## 实时网络质量监测

主菜单选择“实时监测连接质量”后，程序会列出已启用的有线和 Wi-Fi 连接。
选择目标后会自动识别连接方式，并显示一个综合质量等级。两类连接都会自动使用该
网卡的路由器地址进行低流量探测，界面每 0.25 秒刷新，并以最近 20 次结果滚动计算
丢包率和平均延迟。全屏界面同时保留最近约 30 秒的历史曲线，左侧较早、右侧最新；
每项指标使用双行、16 级纵向精度并尽量占满终端宽度，曲线之间留有空行，便于分辨
细小变化。在曲线页按 `Esc`、`Q` 或点击停止按钮会回到网络选择页；在网络选择页
再次按 `Esc` 或点击“返回主菜单”才会回到主菜单。纯文字模式中按 `Ctrl+C` 停止。

- Wi-Fi：显示信号百分比、dBm、增强/减弱趋势和无线接入点切换；没有 `iw` 时自动
  使用 NetworkManager 的信号百分比。
- 有线：显示网线物理链路、协商速率、双工模式，以及本周期新增的错误/丢弃包。

没有 IPv4 网关的摄像头或直连网络不会伪造丢包数据，只评估物理链路。部分网关可能
禁用 ICMP，此时 100% 丢包只表示网关没有响应质量探测。所选连接停用或切换后，监测
会自动结束并返回菜单。

## 统一网络健康检查

菜单 15 会依次检查 IPv4 默认路由抢占和当前活动网卡的 IPv4 网段冲突。发现网段
重叠时会显示冲突双方，并列出能够映射到活动有线/Wi-Fi NetworkManager profile 的
连接。程序不会自动决定修改哪一侧或使用哪个优先级；用户可以明确选择一个连接，输入
1～9999 的 route metric，并输入 `SET PRIORITY` 确认，也可以选择删除确认不再需要的
一侧。删除已启用连接需要输入 `DELETE ACTIVE`，承载当前 SSH 时还会额外警告。虚拟
网卡、手工添加的地址或非 NetworkManager 管理的接口只报告冲突，不提供自动修改。
删除成功后，工具会等待旧 IPv4 地址和路由从内核中清理完成再重新检查，避免把异步
清理期间的旧地址再次报告为冲突。

同一现场内网同时连接有线和 Wi-Fi 时，两张网卡必须使用不同 IP。若两侧是完全相同
的网段，并且内核中的有效 route metric 明确不同，健康检查会将其标记为“主备网络”，
显示主用和备用接口，不再要求删除连接。重复 IP、相互包含但不完全相同的网段、相同
metric 或无法确定 metric 的情况仍按严重冲突处理。路由优先级只决定首选联网方式，不会
叠加两张网卡的带宽。

程序启动时仍会自动解析 `ip -4 route show default`，并结合路由的
`linkdown`、网卡 carrier 和 metric 判断内核的实际选路。例如：

```text
default via 10.205.30.254 dev eth0
default via 192.168.2.1 dev wlan0 metric 600
```

如果 `eth0` 已无链路，程序会判定 metric 0 的坏路由仍优先于 metric 600 的
`wlan0`，并在主菜单之前直接提醒修复。也可随时选择菜单 15 重新检查。

- 临时移除：只删除当前内核中的坏路由，不修改 NetworkManager profile；
- 仅局域网：永久设置 `ipv4.never-default=yes`，适合摄像头或内网专口；
- 设置优先级：由用户选择要修改的问题路由或可用路由，再输入明确的 route metric；
  程序不再自动使用“另一条路由加 100”的数值。

上述修复只针对 IPv4 默认路由，不会删除网卡 IP 或其他明确的局域网路由。每项配置
变更都需要用户选择目标、输入参数并再次确认。

## 通过 SSH 修改当前网卡

切换当前远程连接所使用的网卡后，原 SSH 会话可能立即断开，这不代表设置失败。

1. 记下工具显示的新 IP。
2. 使用新 IP 重新建立 SSH。
3. 在 120 秒内再次运行同一个 C 工具。
4. 输入大写 `YES` 保留新设置；输入 `ROLLBACK` 可立即使用修改前的连接。

等待确认的信息保存在 `/run/first_net_config`，仅 root 可访问。等待期间不要重启设备。

## 提前配置异地 Wi-Fi

配置无线网络时选择“仅保存，暂不连接”，可以在目标 Wi-Fi 不在附近时预先填写 SSID、
密码和 IPv4 参数。此模式只支持永久配置；保存成功后会开启自动连接，并设置
较高的自动连接优先级。保存过程不会主动切换当前网络，也不会因为现场搜索不到目标
Wi-Fi 而删除配置。

由于目标网络不在现场，工具无法提前验证 SSID、密码、DHCP、固定 IP、网关或 DNS
是否正确。设备启动、无线网卡重新连接或当前 Wi-Fi 断开时，NetworkManager 会在可用
网络中选择自动连接；如果设备已经连着另一个 Wi-Fi，目标网络出现后通常不会强制抢占
当前连接。隐藏网络需要在配置时明确选择“隐藏名称（SSID）”。

## 摄像头发现的边界

SADP/ONVIF 搜索通常不需要认证，但结果取决于摄像头固件。程序会忽略本机回环收到的
Probe 请求和本机其他网口的源地址，避免把 RK3588 自己误列为摄像头。IP 一般可以获得，
子网掩码、网关和服务端口可能需要人工填写。工具只设置 RK3588 所选网口，不修改摄像头
IP、激活状态、账号或密码。保存后的摄像头连接同样属于系统连接，Web 的通用网络页
可以看到并继续管理它。

## 系统初始设置与清除全部连接

系统初始设置只能在制作镜像或确认设备仍处于初始状态时保存，默认位于：

```text
/var/lib/first_net_config/
```

菜单 14 的“清除所有已保存的连接”不依赖初始设置。它会清除有线固定 IP、自动地址、
无线网络名称和密码等系统连接，不会删除网络服务、网卡驱动或本工具。执行前会显示
清单、保存紧急备份并要求完整确认；立即清除可能中断当前 SSH。

## 当前边界

- 系统初始设置恢复采用“写回后重启生效”，工具不会自动重启设备。
- 摄像头连接使用完整摄像头子网；发现与其他网卡重叠时会明确警告。
- 暂不支持 VLAN、PPPoE、需要账号或证书的企业无线网络、蜂窝网络和 IPv6 配置。
