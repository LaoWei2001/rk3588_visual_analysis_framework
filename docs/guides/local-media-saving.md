# 告警原图导出与电脑端录像保存

在告警事件箱中，可按时间、事件类型和媒体类型筛选。未勾选记录时，导出和删除作用于所有匹配记录，包括列表前 500 条以外的结果。勾选后，两个按钮都会显示所选范围的数量。切换筛选会保留勾选，并显示其中有几条在当前筛选外。“全选筛选结果”只改变当前筛选范围的勾选状态。点击顶部工具栏的“清空整个事件箱”并确认，即可删除全部记录。

打开告警图片后可勾选“选择此图”，用上一张、下一张或键盘 ↑、↓ 连续选图。同一条记录中的原图、标注图和视频可在预览窗口切换。

导出将所选范围内的 `raw.jpg` 归入 ZIP，下载到访问网页的电脑。没有原图的记录会被跳过。ZIP 分块传输，导出期间消失的原图会列入 ZIP 内的说明文件。

视频采集在开始前选择电脑上的 MP4 文件。后端通过独立的有界管道将 MP4 传到浏览器，
JPEG 预览使用另一条管道，不创建板端录像文件。不支持本地文件选择器时由浏览器
直接下载实时 MP4，保存位置由浏览器下载设置控制。达到大小上限或点击停止后发送
EOS 完成当前文件；下载中断、取消或长时间不读取会停止采集。

录制期间需要保持网页和下载连接开启。电脑磁盘写入失败时，本地文件保存流程会
报错并停止采集。通过下载方式保存时，网页显示的是服务端已传输的字节数，最终
是否保存成功应以电脑浏览器的下载结果为准。

浏览器的目录/文件保存选择器要求安全上下文，并不支持所有浏览器。普通局域网
HTTP 页面会使用下载方式；若需要每次选择保存位置，在浏览器设置中开启
“下载前询问保存位置”。页面不能读取或替用户修改浏览器的默认下载目录。

现有测试：`web_console/backend/tests/test_record_export.py` 覆盖选择范围、原图字节、全量导出和清空；
`web_console/backend/tests/test_capture_computer.py` 使用真实 GStreamer 管线检查可播放 MP4、无板端文件、
大小限制，以及 HTTP 下载取消后进程退出。

这些测试需要对应依赖和运行环境；测试源码的存在不表示当前板端或浏览器已完成验收。
