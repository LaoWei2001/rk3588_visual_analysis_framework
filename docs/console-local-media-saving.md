# 告警原图导出与电脑端录像保存

告警记录每行显示一条，左侧支持勾选和选择当前列表。勾选后，右上角按钮变为
“清空所选记录”和“导出所选原始图片”；取消所有选择后恢复操作全部记录。
切换筛选条件时清除选择，定时刷新时保留仍存在的所选记录。

原图导出只读取事件的 `raw.jpg`，不会用标注图替代原图。全部导出扫描完整事件目录，
不受列表 500 条显示上限限制。支持本地目录选择器的浏览器直接将 JPEG 保存到所选
电脑目录；其他浏览器下载包含原图的 ZIP。ZIP 分块生成并传输，不写板端临时文件。
没有原图的记录会被跳过；导出过程中已被清理的原图会列入 ZIP 内的说明文件。

视频采集在开始前选择电脑上的 MP4 文件。后端通过独立的有界管道将 MP4 传到浏览器，
JPEG 预览使用另一条管道，不创建板端录像文件。不支持本地文件选择器时由浏览器
直接下载实时 MP4，保存位置由浏览器下载设置控制。达到大小上限或点击停止后发送
EOS 完成当前文件；下载中断、取消或长时间不读取会停止采集。

录制期间需要保持网页和下载连接开启。电脑磁盘写入失败时，本地文件保存流程会
报错并停止采集。通过下载方式保存时，网页显示的是服务端已传输的字节数，最终
是否保存成功应以电脑浏览器的下载结果为准。

浏览器的目录/文件保存选择器要求安全上下文，并不支持所有浏览器。普通局域网
HTTP 页面会使用下载方式；若需要每次选择保存位置，在浏览器设置中开启
“下载前询问保存位置”。页面不能读取或替用户修改浏览器的默认下载目录。

验证：`test_record_export.py` 验证选择范围、原图字节、全量导出和清空；
`test_capture_computer.py` 使用真实 GStreamer 管线验证可播放 MP4、无板端文件、
大小限制，以及 HTTP 下载取消后进程退出。
