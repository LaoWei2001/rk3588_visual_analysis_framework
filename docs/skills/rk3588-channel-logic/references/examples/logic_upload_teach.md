# logic_upload_teach — 按钮上报告警示例

- 源码：`vision_analysis/src/logic/modules/logic_upload_teach/logic.cpp`
- 模块清单：同目录 `logic.json`
- 事件类型：`upload_teach_demo`
- 触发方式：Web 动作“生成报警事件”

这是一个最小上报示例：点击 Web 按钮后，logic 会在下一业务帧调用一次 `alarm_report()`。事件生成的图片、视频和投递目标完全由当前连接的告警节点配置决定；模块本身不绘制任何额外文字或图形，也不直接发送 HTTP 请求。

## 使用方法

1. 在目标通道连接持续出帧的视频源和此 logic，选择“按钮上报告警示例”。
2. 从 logic 节点连接一个或多个告警节点，按需配置图片上报或视频上报的目标地址、媒体叠加方式和视频前后窗。
3. 保存配置并启动 App，打开实时画面。
4. 在目标通道的“通道控制”区域点击“生成报警事件”。
5. 在事件记录或上传服务日志中查看生成的事件和各投递结果。

一次点击只创建一个独立事件，但该事件可以按告警节点配置同时生成图片、视频，并投递到多个目标。`alarm_report()` 返回非空事件 ID 仅表示事件已经进入本地发件箱；远端投递状态以事件清单和上传服务记录为准。

如果按钮未出现，确认 App 使用的是重新打包后的 `logics.json`，然后关闭并重新打开实时画面。
