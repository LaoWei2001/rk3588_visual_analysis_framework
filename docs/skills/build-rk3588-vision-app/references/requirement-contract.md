## 3. 业务状态机

- 触发条件：

建议先写状态表：

| 当前状态 | 输入条件 | 下个状态 | 动作 |
|---|---|---|---|
| CLEAR | 条件满足 | PENDING | 记录单调起始时间 |
| PENDING | 持续达到阈值 | ALARM | 创建一次事件 |
| ALARM | 目标离开/恢复 | CLEAR | 清闩锁 |

状态名只是模板，按真实业务删改。

## 4. 显示与媒体

- 实时画面：框、掩码、轨迹、ROI、中文/英文状态、性能信息

- 哪些自定义绘制属于 `DISPLAY`、`MEDIA` 或两者：

## 5. 配置与外部契约

- `logic_parameters`：key、类型、默认值、范围、单位、热重载策略
- `actions`：按钮 ID、显示名、是否只设置 pending 状态
- `outputs`：通道向全局公开的 key、类型、含义
- `event_types`：事件 ID 与中文名
- `report_fields`：key、string/number/boolean/json 类型、来源
- 远端接口：已有 contract/profile ID；若未确认，不在 logic 中猜 URL、密钥或 target 字段
