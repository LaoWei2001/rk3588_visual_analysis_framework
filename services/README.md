# 框架 Service

`services/framework/` 只保存随底层仓库升级的内置服务。目前包括统一上传、模型 OTA 和
GPIO 状态恢复、系统看门狗和独立故障恢复监测，以及可配置有线/Wi-Fi 管理出口的网络恢复守护。
二次开发者不要在这里放客户代码，否则升级底层仓库时仍会产生合并冲突。

应用构建只打包这里明确登记的框架 Python 服务，不再扫描业务工作区中的自定义 Service。
`runtime_manager` 和 `system_watchdog` 属于整机平台，由根安装器和独立的离线平台包安装，
不随单个视觉应用重复打包。运行管理库不依赖 Web；Web 仅管理系统服务和持久配置。
